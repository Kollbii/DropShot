# Deliverable 4: Glossary of Approved Terms (ASD-STE100)

This glossary enforces **1 word for 1 meaning** across all screens, buttons, labels, and messages in DropShot. Every word is classified as an **Approved STE word**, a **Technical Name (TN)**, or a **Technical Verb (TV)**.

## 1. Nouns and Technical Names

| Approved Term | Category | Approved Meaning in DropShot | Do-Not-Use Synonyms |
|---|---|---|---|
| **account** | TN | The optional Google user profile used to back up match data to the cloud. | login, user ID, membership |
| **app** | TN | The DropShot Android software application. | program, software, tool, utility |
| **backup** | TN | A saved copy of match history and player profiles in the cloud. | archive, snapshot, cloud copy |
| **Bluetooth** | TN | The wireless technology used by media remote controls and the watch bridge. | BT, wireless link |
| **button** | Approved (noun) | An interactive control that starts an action when the user taps or presses it. | key (on screen), trigger, cta |
| **chart** | TN | A visual graph that shows point history or game progress. | graph, plot, diagram, visualization |
| **clock** | TN | The timer that shows elapsed match time (`mm:ss` or `hh:mm:ss`). | stopwatch, chrono |
| **color** | Approved (noun) | The visual identity hue assigned to a player (`Blue`, `Red`, `Green`, `Gold`). | shade, tint, swatch, hue |
| **comparison** | TN | A side-by-side table of statistics for 2 players. | versus view, head-to-head page, matchup |
| **court** | TN | The squash playing area rented for a fixed duration. | field, pitch, arena, room |
| **court timer** | TN (2 nouns) | The countdown timer for the court rental duration. | rental clock, booking timer, court alarm |
| **data** | Approved (noun) | Saved match records and player profiles. | info, information, content |
| **duration** | TN | The length of time of a match, a game, or a court rental (in `min` or `s`). | length, span, period |
| **error** | Approved (noun) | A failure condition that stops an operation. | bug, fault, issue, problem, glitch |
| **filter** | TN | A chip control that narrows the list of matches. | facet, refinement, tag |
| **game** | TN | One unit of a squash match (default: 11 points with a 2-point lead). | set (in UI text), round, frame |
| **game ball** | TN (2 nouns) | The score state where 1 more point wins the current game. | set point, set ball, game point |
| **guest** | TN | A temporary player who does not have a saved player profile. | visitor, anonymous player, temp |
| **history** | TN | The saved list of up to 100 past or unfinished matches. | log, archive, journal, past games |
| **key** | Approved (noun) | A physical button on a Bluetooth remote control (`Volume +`, `Volume -`, `Next track`, `Previous track`). | hardware button, switch, trigger |
| **list** | Approved (noun) | A vertical sequence of match cards or player rows. | feed, index, catalog, directory |
| **match** | TN | A complete squash contest between Player 1 and Player 2. | contest, fixture, bout, session |
| **match ball** | TN (2 nouns) | The score state where 1 more point wins the entire match. | match point, championship point |

| **network** | TN | The internet connection used for optional cloud backup. | web, Wi-Fi connection, online link |
| **panel** | Approved (noun) | The large left or right score area for Player 1 or Player 2 on the Match screen. | box, tile, zone, pad |
| **player** | TN | A person who participates in a squash match or has a saved profile. | user (on court), athlete, competitor, contender |
| **point** | TN | The basic scoring unit won after a squash rally. | rally point, tally, mark |
| **profile** | TN | A saved player record with a stable ID, a name, and a color. | account (for local player), card, bio |
| **remote control** | TN (2 nouns) | A Bluetooth media controller used to change the score. | clicker, remote, fob, controller |
| **rule** | TN | A numeric setting for a match (points to win a game, games to win a match). | regulation, law, format, mode |
| **score** | TN | The count of games and points for Player 1 and Player 2. | tally, result, standing |

| **streak** | TN | The highest number of consecutive points won by 1 player in a match. | run, series, chain |

## 2. Approved Verbs (Action Labels and Instructions)

Every button label in DropShot starts with one of these approved imperative verbs. The same verb is always used for the same action across all screens.

| Approved Verb | Category | Approved Meaning in DropShot | Standard Button Label Examples | Do-Not-Use Synonyms |
|---|---|---|---|---|
| **add** | Approved (verb) | Increase a count by a number, or create a new player profile. | `Add 1 point`, `Add 3 games`, `Add player` | create, insert, plus, increment, new |
| **cancel** | TV | Close a dialog or operation without saving changes. | `Cancel action` | abort, dismiss, nevermind, back out |
| **clear** | Approved (verb) | Empty the text in a search field or reset filters. | `Clear search`, `Clear filters` | erase, wipe, empty, blank |
| **close** | Approved (verb) | Dismiss a detail view, fullscreen chart, or dialog. | `Close chart`, `Close dialog` | exit, quit, hide, done |
| **compare** | Approved (verb) | Open the comparison dialog or view for 2 players. | `Compare players` | contrast, match up, pit |
| **continue** | Approved (verb) | Proceed without signing in. | `Continue without account` | proceed, bypass |
| **delete** | TV | Permanently remove a match record or a player profile. | `Delete match`, `Delete player` | remove, trash, destroy, drop, erase |
| **discard** | TV | Leave a settings dialog without saving modified inputs. | `Discard changes` | throw away, abandon, forget |
| **edit** | TV | Modify an existing player profile's name or color. | `Edit player` | modify, update, change, rename, alter |
| **keep** | Approved (verb) | Stay in the current dialog and preserve unsaved edits. | `Keep editing` | stay, remain, hold |
| **manage** | TV | Open the account and cloud backup screen. | `Manage account` | administer, configure account |
| **open** | Approved (verb) | Navigate to another screen or load a finished match onto the board. | `Open help`, `Open match`, `Open settings` | launch, view, go to, visit |
| **pause** | TV | Stop the match clock and lock point scoring temporarily. | `Pause match` | hold, freeze, suspend, halt |
| **reset** | TV | Set the court timer back to the current full hour, or reset chart zoom. | `Reset court timer`, `Reset zoom` | restart, zero, reinitialize |
| **resume** | TV | Continue a paused or unfinished match. | `Resume match` | unpause, continue match, restart |
| **retry** | TV | Run a failed loading or sync action again. | `Retry load`, `Retry sync` | try again, repeat, reload |
| **save** | TV | Store modified settings or a player profile. | `Save settings`, `Save player` | apply, store, commit, confirm, ok |
| **search** | TV | Find match records or player profiles that match a text query. | `Search matches` | find, look up, query, locate |
| **select** | Approved (verb) | Choose a player profile, a color, a rule, or a filter chip. | `Select player`, `Select filter` | pick, choose, opt for |
| **set up** | Approved (phrasal verb) | Configure the players, colors, and rules before a match. | `Set up match` | configure, prepare, customize |
| **show** | Approved (verb) | Display a screen, chart page, or next onboarding step. | `Show next step`, `Show all games`, `Show comparison`, `Show match details`, `Show match board` | display, reveal, view, see |
| **sign in** | TV | Authenticate with a Google account for optional cloud backup. | `Sign in with Google` | log in, logon, authenticate |
| **sign out** | TV | Disconnect the Google account from the device. | `Sign out of account` | log out, logoff, disconnect |
| **skip** | TV | Exit the onboarding flow and open the Match screen immediately. | `Skip intro` | bypass, jump over, ignore |
| **start** | Approved (verb) | Begin a new match, start the court timer, or finish onboarding. | `Start new match`, `Start court timer`, `Start app` | begin, kick off, initiate, play |
| **stop** | Approved (verb) | Turn off the active court rental timer. | `Stop court timer` | turn off, disable, end, kill |
| **sync** | TV | Upload and download match history and profiles to the cloud backup. | `Sync data now` | synchronize, upload, refresh cloud |
| **tap** | TV | Touch a screen element once with a finger. | Used in instructions: `Tap a player panel to add 1 point.` | click, press (on screen), hit, poke |
| **undo** | TV | Revert the last point added in the current match. | `Undo point` | revert, step back, take back, cancel point |

## 3. Units and Number Formatting Rules (ASD-STE100 + SI Units)

| Quantity | Unit Symbol | Format Rule | Approved Examples in DropShot |
|---|---|---|---|
| **Time (seconds)** | `s` | Digits + space + `s` | `15 s`, `0 s` |
| **Time (minutes)** | `min` | Digits + space + `min` (SI accepted non-SI unit) | `60 min`, `30 min`, `15 min`, `5 min` |
| **Clock display** | `mm:ss` or `hh:mm:ss` | Tabular digits with colon separator | `14:08`, `01:05:22`, `19:00` |
| **Distance** | `m` | Digits + space + `m` | `6 m` |
| **Percentage** | `%` | Digits + `%` | `64%`, `100%`, `200%` |
| **Counts (points, games, matches)** | Digits + noun | Always use digits (`1`, `2`, `3`, `11`, `100`), never spell out numbers | `1 point`, `2 players`, `3 games`, `11 points`, `100 matches` |
| **Noun cluster limit** | Maximum 3 nouns | Break longer strings with prepositions (`of`, `for`, `in`, `to`) | Use `settings for the court timer` or `court timer settings` (3 nouns), never `court rental warning timer settings` (5 nouns). |
